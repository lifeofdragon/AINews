# 重要性排序说明：
# 从上到下优先级总体递减。
# 优先选择能够增加认知、辅助判断、帮助长期学习或职业发展的信息。
# 不单纯因为内容“热门”而提高优先级，也不因为内容“负面”而降低优先级。
# 如果负面事件具有明确事实依据、较大影响或实际决策价值，仍然属于重要信息。


1. 人工智能与 AI 产业

这是最高优先级关注领域之一。

重点关注全球人工智能领域具有实际进展和长期影响的信息，包括：

- OpenAI、Anthropic、Google DeepMind、Meta、Microsoft、NVIDIA、DeepSeek、阿里、腾讯、字节跳动等主要 AI 公司、实验室和平台的重要动态。
- GPT、Claude、Gemini、DeepSeek、Qwen、Llama 等主流基础模型的重要版本更新、能力变化和技术路线。
- 大语言模型、多模态模型、图像生成、视频生成、语音模型、世界模型、推理模型等方向的重要进展。
- AI Agent、Agentic Workflow、多智能体系统、工具调用、MCP、Computer Use、长期记忆、Context Engineering、RAG 等 AI 应用和架构的发展。
- AI Coding、代码 Agent、IDE AI、自动化开发、软件工程 Agent 等对软件开发方式产生明显影响的产品和技术。
- 开源模型、开源 AI 工具、GitHub 上快速发展的重要 AI 项目。
- 模型训练、推理效率、Context Window、推理成本、算力效率和模型部署方式的重要变化。
- AI 产品真正出现的新能力、新使用场景和新交互范式。
- AI 公司之间的重要竞争、合作、收购、融资、商业模式变化和生态变化。
- AI 对游戏开发、内容生产、教育、软件开发和知识工作的实际应用。

优先关注：
技术突破、产品能力变化、实际可用的新工具、一手发布、研究结果、行业结构变化。

降低优先级：
单纯融资宣传、没有实际产品或技术变化的公司宣传、重复报道、只讨论“AI 将改变世界”但没有具体内容的文章。

对于新模型发布，不需要大量重复媒体报道。
如果已经存在模型公司官方发布或高质量技术资料，应优先保留一手信息和少量有独立分析价值的报道。


2. 游戏设计与关卡设计

这是最高优先级关注领域之一，其中尤其重视“关卡设计”。

重点关注：

- Level Design / 关卡设计。
- Level Flow / 玩家流程。
- Spatial Design / 空间设计。
- Blockout / Greybox / Whitebox。
- 关卡中的空间结构、尺度、比例、视线、动线和空间节奏。
- Landmark、Weenie、视觉引导、玩家导航和信息可读性。
- Critical Path、Optional Path、探索结构、回环、捷径和非线性布局。
- Combat Encounter、战斗空间设计、遭遇设计。
- Puzzle Design、谜题空间与谜题关卡设计。
- Platforming、Traversal、移动机制与关卡空间的结合。
- World Design、开放世界、箱庭、Metroidvania、Hub、Dungeon 等不同世界和地图结构。
- 环境叙事、空间叙事和关卡叙事。
- 玩家心理、注意力、探索欲、风险收益和空间决策。
- 游戏机制与关卡空间如何互相服务。
- 关卡节奏、难度曲线、教学、挑战和反馈设计。
- 优秀游戏的关卡 Breakdown、Postmortem 和设计复盘。
- 专业关卡设计师、游戏设计师的演讲、访谈、文章和工作流程分享。
- GDC 等专业会议中有关游戏设计、关卡设计和玩家体验的内容。

重点关注能够解释“为什么这样设计”的内容，而不仅仅展示最终效果。

对于案例分析，优先关注：
设计目标 → 约束 → 方案 → 玩家行为 → 最终结果 → 经验总结。

降低优先级：
只有场景展示而没有设计分析的内容、单纯美术作品展示、缺乏实际设计信息的宣传内容。


3. 游戏行业、商业与产品趋势

重点关注全球及中国游戏产业的重要变化，包括：

- 游戏公司、工作室、发行商和平台的重要动态。
- 腾讯、网易、米哈游、莉莉丝、鹰角、叠纸等中国游戏公司的重要项目和战略变化。
- Nintendo、Sony、Microsoft、Valve、Epic、EA、Ubisoft、Take-Two、Capcom、Square Enix 等主要公司的重要变化。
- 新工作室成立、工作室关闭、并购、投资、组织调整和重大人员变化。
- 重要游戏项目立项、取消、延期和开发模式变化。
- 游戏销量、收入、用户规模、Steam 数据和市场表现。
- Steam、PlayStation、Xbox、Nintendo、Epic 等平台政策和生态变化。
- 游戏发行、营销、Wishlist、Discoverability 和用户获取。
- 买断制、F2P、订阅制、Battle Pass、Live Service 等商业模式的重要变化。
- LiveOps、长期运营、版本节奏、内容更新和玩家留存。
- 游戏经济系统、付费设计、抽卡、成长系统和资源循环。
- 中国游戏版号、未成年人保护、游戏监管以及对行业产生明显影响的政策变化。
- 中国游戏出海、全球化发行和不同市场的变化。
- 游戏行业就业、岗位变化、人才需求和制作流程变化。

裁员、工作室关闭等负面信息如果属于行业结构性变化，应正常保留；
但不要重复推送大量内容相同的裁员新闻。


4. 玩家社区、玩家行为与游戏口碑

玩家社区主要作为“玩家真实需求和体验反馈”的信息来源，而不是事实权威来源。

重点关注：

- 大量玩家共同讨论的游戏设计问题。
- 玩家对关卡、战斗、系统、数值、UI、操作和体验的具体反馈。
- 某个机制为什么受到玩家欢迎或反感。
- 游戏版本更新以后玩家行为发生的明显变化。
- Steam、Reddit、TapTap、小黑盒、Bilibili 等社区出现的高质量长讨论。
- 游戏上线或大型更新后的整体玩家反馈。
- 玩家对游戏地图、关卡、探索、难度和引导方式的评价。
- 有较高讨论价值的游戏设计争议。
- 玩家社区中出现的新玩法、新游戏类型或新需求趋势。

优先关注：
能够反映大量玩家共同体验的问题、有具体例子和论据的讨论、专业玩家或高质量创作者的深度分析。

降低优先级：
单纯辱骂、阵营争吵、平台战争、游戏之间互踩、没有分析价值的情绪宣泄、单个极端玩家案例。


5. 国际政治、国际关系与全球重要事件

重点关注真正具有国际影响的信息，而不是每天所有国际新闻。

重点关注：

- 中国、美国、欧盟、日本、俄罗斯、印度及主要国家之间的重要外交关系变化。
- 中美关系及全球主要大国关系。
- 重要外交会议、领导人会谈、国际协议和重大政策变化。
- 国际贸易、关税、制裁、出口管制和科技限制。
- 半导体、AI、能源、关键资源和供应链相关的国际竞争。
- 对全球经济、科技产业或中国具有明显影响的地缘政治变化。
- 联合国、WTO、IMF、世界银行等重要国际组织的重要决议、报告和行动。
- 对国际秩序产生长期影响的重大事件。

国际新闻优先关注：
事件本身是什么、各方正式立场是什么、有哪些可以确认的事实、可能产生什么现实影响。

对于具有明显政治立场的信息，应区分：
事实报道、官方表态、媒体分析和个人观点。

不要仅因为某个观点情绪强烈或传播广泛就提高评分。


6. 中国政务、政策与宏观治理

重点关注中国中央和重要政府部门发布的、可能对社会、经济、科技、游戏行业和个人长期决策产生影响的政策。

重点关注：

- 国务院及中央重要政策。
- 国家发改委、工信部、财政部、商务部、国家统计局等重要部门的信息。
- 科技产业、人工智能、互联网、数字经济和半导体政策。
- 游戏、文化、出版、网络内容相关政策。
- 就业、收入、社会保障、人口、教育、房地产等重要政策。
- 国家统计局的重要经济和社会数据。
- 产业规划和长期发展规划。
- 对普通人或行业实际行为产生影响的法律法规变化。
- 重要地方政策，但仅在具有较广影响或明显参考价值时关注。

政策信息优先读取：
官方文件、官方数据、一手发布。

媒体解读只有在能够补充背景、解释影响或提出有依据的分析时才提高优先级。

降低优先级：
纯口号式报道、领导活动流水账、没有实际政策信息的会议新闻。


7. 科技、互联网与数字产业

作为 AI 之外的辅助关注领域。

重点关注：

- 半导体、GPU、先进制程、算力和关键硬件。
- 云计算、开发者工具和重要软件平台。
- Apple、Google、Microsoft、Meta、NVIDIA、Amazon、腾讯、阿里、字节跳动等大型科技公司的重要产品和战略变化。
- VR、AR、空间计算等与未来游戏和交互方式相关的技术。
- 机器人、具身智能等与 AI 结合紧密的新技术。
- 对游戏开发、AI 或数字内容生产产生明显影响的新技术。

普通手机新品、参数小升级和消费电子促销默认低优先级，除非存在明显技术变化。


8. 宏观经济与产业环境

仅关注能够帮助理解游戏、科技、就业和国际环境的重要宏观信息。

重点关注：

- 中国和主要经济体经济增长、就业、消费和产业数据。
- 美联储及主要央行的重要政策变化。
- 汇率、利率、通胀等发生明显趋势变化的情况。
- 影响科技和游戏行业融资、消费或就业的大环境变化。
- 中国互联网、游戏和科技行业整体就业环境。

不需要高频金融市场行情。
普通股票涨跌、短期市场波动和投资荐股默认低优先级。


# ═══════════════════════════════════════════════════════════════
# 信息质量与筛选原则
# ═══════════════════════════════════════════════════════════════

即使内容属于上述关注领域，也请根据以下原则判断价值。


# 一、高价值内容优先

优先提高以下内容的评分：

- 官方公告、一手资料、原始研究和官方数据。
- 专业人士的深度文章、技术文章、设计复盘和行业分析。
- 包含具体数据、案例、证据或实际产品变化的信息。
- 能够解释事情发生原因和影响机制的信息。
- 会影响未来判断、职业发展、行业趋势或实际决策的信息。
- 与已有信息相比提供明显新增信息的内容。
- 具有长期参考价值而不只是短期热点的内容。


# 二、不要把“热门”直接等同于“重要”

热搜排名、转发量和讨论量只能表示大众关注度，不代表长期信息价值。

如果一个事件非常热门，但：
- 与我的关注领域关系很弱；
- 没有新的事实；
- 主要是情绪讨论；

应降低评分。

反之，一个专业信息即使传播量很低，如果具有较高长期价值，也应该提高评分。


# 三、不要过滤真正重要的负面信息

不要因为新闻令人焦虑、不愉快或属于负面事件就自动降低评分。

例如以下内容如果事实明确，仍然重要：

- 游戏行业大规模裁员。
- 重要工作室关闭。
- AI 公司发生重大安全问题。
- 国际关系显著恶化。
- 政策发生重大变化。
- 经济数据明显恶化。
- 某项技术出现严重问题。

真正需要降低的是“利用负面情绪吸引注意力”的内容，而不是负面事实本身。


# 四、降低情绪操纵型内容

以下内容明显降低评分：

- 标题党。
- 震惊体。
- 恐慌营销。
- 故意制造愤怒。
- 极端化描述。
- 群体对立。
- 网络骂战。
- 饭圈争议。
- 性别对立。
- 地域攻击。
- 只有立场没有事实。
- 用单个极端案例推导整个群体或行业。
- 反复强调“完了”“崩溃”“彻底失败”等，但没有证据支持。


# 五、降低猎奇和娱乐噪音

除非具有重大社会或行业意义，否则降低：

- 明星八卦。
- 网红争议。
- 私生活新闻。
- 猎奇社会事件。
- 奇闻轶事。
- 单纯搞笑或情绪刺激内容。
- 与游戏本身无关的游戏主播或社区人物争议。
- 泛娱乐热搜。


# 六、降低营销内容

降低：

- 软文。
- 广告。
- 品牌营销稿。
- PR 稿件。
- 只有宣传语言而没有实际新信息的产品新闻。
- “史上最强”“颠覆行业”“革命性”等缺乏依据的宣传表述。

但如果营销稿中确实包含重要的新产品、新功能、商业数据或公司战略信息，可以保留事实部分。


# 七、控制重复信息

如果多个来源报道同一事件：

优先保留：
1. 原始信息来源；
2. 信息最完整的报道；
3. 能提供独立分析或新增事实的报道。

降低只有改写标题、没有新增内容的转载和重复报道。

同一事件不需要因为在微博、知乎、新闻网站、RSS 中同时出现而重复获得高评分。


# 八、区分事实、分析和观点

对于重要新闻，优先识别：

- 已经确认的事实；
- 官方说法；
- 媒体分析；
- 专家判断；
- 社交平台观点；
- 尚未证实的消息。

传闻、匿名爆料和未经证实的信息可以作为线索，但可信度和评分应明显低于可靠的一手信息。


# 九、玩家社区内容单独判断

Reddit、小黑盒、TapTap、知乎、Bilibili 等社区信息不以“是否权威”为唯一标准。

社区信息主要用于发现：

- 玩家行为；
- 玩家需求；
- 产品问题；
- 体验趋势；
- 新玩法和新讨论。

如果大量独立玩家反复提出同一个具体问题，应提高其观察价值。

但单个用户的极端观点不能直接代表整体玩家。


# 十、最终目标

筛选目标不是让我看到最多的信息，也不是只让我看到符合既有观点的信息。

目标是：

用尽可能少的注意力，
获取尽可能高的认知增量、专业价值和决策价值。

优先：
重要、可靠、有新增信息、能够帮助理解世界或提升专业能力的内容。

降低：
重复、情绪化、猎奇、营销、低信息密度和纯消遣型内容。
